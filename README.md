## 1. Концепция и Бизнес-задача

* **Ниша:** Премиальный мужской клуб и барбершоп (г. Москва, ул. Кузнецкий Мост).
* **Проблема заказчика:** Сторонние сервисы онлайн-записи (Yclients, Dikidi) берут ежемесячную абонентскую плату, ограничивают кастомизацию бренда и не дают продавать сопутствующую косметику до визита. Конверсия со смартфонов на стандартных виджетах страдала из-за перегруженных экранов.
* **Цель проекта:** Создать автономный, статусный, конверсионный веб-сервис с собственным мастером онлайн-бронирования за 60 секунд, витриной селективной косметики и интерактивной демонстрацией результатов «До / После».

## 2. Ключевой функционал

### 💈 1. Четырехшаговый визард онлайн-записи (Booking Flow)
* **Шаг 1: Выбор услуги.** Фильтрация по категориям (Стрижки, Борода, Комплексы, СПА) с расчетом длительности и стоимости.
* **Шаг 2: Выбор мастера.** Профили барберов с фото, опытом, специализациями, рейтингом и опцией «Ближайший свободный».
* **Шаг 3: Дата и время.** Динамический интерактивный календарь на 7 дней вперед + сетка доступных тайм-слотов.
* **Шаг 4: Контакты & Валидация.** Моментальная валидация номера телефона и имени гостя, блок заметок (кофе, пропуск на парковку).
* **Шаг 5: Экран подтверждения.** Генерация уникального номера брони (`#BT-XXXX`) и сводка параметров записи.

### ✂️ 2. Интерактивный Before/After слайдер
* Слайдер с плавным перемещением шторки для сравнения стрижки «До» и «После».
* Полная поддержка мыши и сенсорных экранов (Touch events) с нулевым сдвигом макета (Zero CLS).

### 🧴 3. Витрина мужской косметики (Apothecary & Care)
* Линейка премиального ухода (масла для бороды, матовая глина, твердый шампунь).
* Интерактивная бронь товаров к визиту в один клик.

### 🏛 4. Bento Grid: Клубный сервис
* Акцентные карточки: бесплатный бар со спешелти-кофе и виски, 4-ступенчатая стерилизация инструмента по СанПиН в автоклаве, лаунж с PS5 и Chesterfield, закрытый клуб постоянных резидентов.

### 📱 5. Mobile-First & Sticky CTA
* Плавающая кнопка быстрой записи при скролле на смартфонах.
* Адаптивное меню-шторка с быстрым вызовом звонка и адреса.
* Интерактивное копирование адреса и вызов навигатора.

## 3. SEO & Производительность

* **Schema.org:** Микроразметка `BarberShop` (адрес, гео-координаты, часы работы, диапазон цен, телефон).
* **Open Graph & Twitter Cards:** Настроенные превью для шеринга в Telegram, WhatsApp и соцсетях.
* **Семантика HTML5:** Логическая иерархия заголовков (`h1` -> `h2` -> `h3`), семантические теги `header`, `nav`, `main`, `section`, `footer`.
* **Быстродействие:** Оптимизированные стили Tailwind, предзагрузка шрифтов Google Fonts (`preconnect`, `font-display: swap`).

## 5. Быстрый старт и запуск

```bash

cd "C:\Users\user\.gemini\antigravity\scratch\blade-and-timber"

# Установка зависимостей (если еще не установлены)

npm run dev

# Сборка продакшн-бандла
npm run build

# Локальный предпросмотр продакшн-сборки
```
